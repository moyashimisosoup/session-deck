# UI改善 v2：Linearから学ぶ、静かな開発管理画面

更新：2026-10-17  
対象：Session Deckの公開アプリ台帳（`portfolio.html`）  
目的：21件以上のアプリについて「いま／最後のコミット／次の一手」を瞬時に比較でき、必要に応じてキーボードで移動できること。

## 今回の変更

1. 主画面の情報量は維持。色彩、パネルの高さ、余白、境界線、状態ラベルの視覚的強弱を整理。
2. ダークを既定テーマとし、ヘッダー右のボタンでライトへ切替。端末内に**テーマ名のみ**を保存。端末間同期なし。
3. Ctrl/⌘+Kで、アプリ検索・絞込ビューへの移動・テーマ切替を1つのメニューから実行。
4. J/Kまたは上下矢印でアプリを選択。Enterで詳細を開閉。入力欄を編集中はこれらのキーを奪わない。
5. /で一覧の検索欄へ移動。Escは操作メニューの終了、または選択状態の解除。
6. スマートフォンでは通常のタップ操作を中心にし、コマンドメニューの起動ボタンをヘッダーに常時表示。
7. `prefers-reduced-motion` を尊重し、不要なアニメーションや大きな動作は追加しない。
8. 既存のGitHub公開メタデータ取得、レビュー基準、確認依頼コピー、README/台帳の書き換え規則には手を加えない。

**重要：Linearのロゴ、製品画像、スタイルシート、ソースコードは転載していない。UI上の設計原則だけを参考にし、実装は独立したHTML/CSS/JavaScript。**

## 技術構成と他作業への影響

- 既存ファイル `portfolio-ui.css` と `portfolio-ui.js` が情報表示の基本となる。
- 新規 `portfolio-polish.css` が配色・視覚階層を追加で定義する。
- 新規 `portfolio-shortcuts.js` が検索・キー操作・テーマ切替を追加する。
- `portfolio-ui.js` は読取り専用ナビゲーション用の小さなAPIのみを外に出す。書込み権限は増やさない。
- 既存 `index.html`/`app.js`/`motion.js`/`motion.css` は変更しない。
- UI表示改善を含むPRは独立ブランチでテスト後マージし、Pagesの公開動作を検証する。

## 受入検証

| 項目 | 判定方法 |
| --- | --- |
| 従来の21件の表示 | 公開URLで件数が維持される |
| 3つの主要情報 | 行内に台帳の状態、GitHub最終コミット、次の一手が表示される |
| Cmd/Ctrl+K | モーダルが開き、アプリ検索→詳細へジャンプできる |
| J/K/Enter/ /Esc | 選択・展開・検索フォーカス・解除が期待通り動く |
| ライト／ダーク | 切替でき、文字・ラベル・詳細のコントラストが維持される |
| キーボード入力保護 | 検索入力中のJ/K等が意図しない行移動にならない |
| モバイル | 390pxと320pxで左右スクロールなくボタンと行内容が読める |
| CIと公開 | Node構文、Python回帰テスト、Pages配信、公開ページでの主要表示 |
| 実機 | iPhone Safariのタップと画面内キーボードは現物確認するまで未検証 |

## 今後

- 実機の文字サイズ・タップ領域・スクロールを評価する。小さすぎる文字があれば密度より読みやすさを優先する。
- キーボードコマンドに詳細リンク・Issueの閲覧などを徐々に加える。画面操作からのGitHub書込みは採用せず、必ず別途承認と検証を行う。
