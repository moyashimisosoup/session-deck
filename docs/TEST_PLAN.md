## 入力の安全性とデータ品質

- HTML/JSを含む文字列を入力しても実行されず、画面に文字として表示される。
- 長い作業名、空欄、不明ステータス、欠損IDの扱いを確認する。
- JSONエクスポートはローカル入力値を含むので、公開前に内容確認を促す。
- 機密性が高い実データを使わない。テストは架空値のみとする。
- 利用端末、ブラウザ、バージョン、試験日時、結果、再現手順を記録する。

## 証跡の扱い
