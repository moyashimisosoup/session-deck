- **本サイトの全782件を複製したものではない。** 最新の例・見本の動きは必ず元サイトで確認する。

- サイト上で「コードをコピー」「再現用HTMLを保存」の機能があっても、ここに再配布する権利が付与されたものとは扱わない。
- 書式を自作して再現するときは、原サイトの解説を丸写しせず、目的に必要な最小の時間・運動・状態変化を新しく設計する。
