## 何を参照するか

投稿者はAI画像・資料の作成時、曖昧な「おしゃれな色」ではなく、名前と5色の見本をセットにして伝えることを提案している。投稿本文の例は「桜ミルク」（やさしく可愛く）、「氷河ブルー」（すっきり爽やか）、「レトロ喫茶」（落ち着いた雰囲気）。これらは**投稿内の例示**であり、当ライブラリでは100配色の個々のHEX値を検証済みとして主張しない。

## 制作時の使い方

1. 制作対象の雰囲気を短く決める（例：やさしい、爽やか、落ち着いた）。
2. 上の図解から配色を一つ選び、必要なら画像か確認済みのHEX値を制作指示に添える。
3. 選んだ5色を **background / surface / text / accent / subaccent** などの役割に割り当てる。画像に載っている順番がUIの役割を指定するとは限らない。
4. 本文コントラスト、押せるボタンの識別、ダークモード、iPhone実機の見やすさをチェックする。見本色を機械的に全て採用しない。

### Codex・画像生成向け指示例

> 配色の参考は共通デザインライブラリ COL-0001（出典: https://x.com/Codex_jisen/status/2111065217006473664 ）とする。添付する見本画像から指定のパレットを参考に、5色を用途別のデザイントークンへ割り当ててください。文字と背景のコントラスト、色以外による状態表現、iPhone幅での可読性を優先し、安易な色の追加を避けてください。参照画像をアプリに直接組み込まないでください。
