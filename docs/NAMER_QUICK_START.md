# Session Deck Namer v0.6.0：使い始める手順

作業ごとに一度許可しておけば、今後の会話は**作業の登録だけで正式名が付きます**。会話ごとの自動改名ON操作は不要です。

## 最初の設定

1. Chromeの拡張機能画面で、読み込み元が `D:\dev\local-env\session-deck\extensions\chatgpt-namer` の「Session Deck Namer」を再読み込みし、ChatGPTの対象会話も再読み込みします。既存データを消したり、拡張を削除・再追加する必要はありません。
2. 対象会話に既存作業を登録し、作業番号・短い作業名・具体的内容を確認します。
3. 「この作業の新規会話を自動命名ON」を押します。この時点の会話を含め、既存会話は一括改名しません。

## 今後の会話

新しい会話の保存後、ページ内パネルから許可済みの作業を選択し、日付・内容を確認して「この作業を会話に登録」を押します。作業一覧の「新規会話は自動命名」が目印です。会話を開いたままサイドバーの対象行を表示しておくと、正式名 `【短い作業名】MMDD・作業番号・具体的内容` を自動で設定し、変更後の表示を確認します。

未登録の作業や会話本文からの推測は行いません。同名なら保存しません。サイドバー読み込み中や別タブにフォーカスがある間は操作せず待機します。

## 止める・やり直す

- 「この作業の自動命名OFF」：その作業の将来の適用と、同じ許可から作った未完了の改名を止めます。
- 「自動改名OFF」：開いている会話だけ止めます。他の会話・作業別許可は維持します。
- 手動変更・失敗・中断した会話は自動再試行しません。再登録や作業別OFF→ONでも再実行しません。画面を確認した後、必要な会話だけ「この会話・候補だけ自動改名ON」で明示的に再許可できます。

許可は端末内に保存し、バックアップ移動では復活しません。詳細と実機での確認範囲は[導入手順](NAMING_RUNBOOK.md)・[CHECKPOINT](APP001_NAMER_CHECKPOINT.md)を参照してください。
