SESSION DECK / NAMING CONSOLE

セッション名を、
同じルールで。

ChatGPT、Claude Code、Codexの名前を統一します。名前を作ってコピーする操作はスマートフォンでも利用可能。外部サービスの名称変更そのものは、各サービスの画面で行います。

1. 名前を組み立てる

本日の日付を初期値に設定。必要なら変更できます。

入力内容はこのページからサーバーへ送信されません。自動保存も行いません。実会話IDや認証情報は入力しないでください。

2. コピーして適用する

正式名称

ChatGPT（iPhoneアプリ / Web）

正式名をコピーして、対象チャットのメニューから「名前を変更」を選んで貼り付けます。PC Web版では別途ブラウザ拡張による改名支援も利用できます。

Claude Code / Codex CLI

対象セッション内に /rename 名前 を入力します。拡張機能や認証情報は不要です。

変更結果の確認

実際のサービスで表示名が変わったことを確認してください。このページでは外部サービスでの保存・同期・変更成功を検証できません。

実運用のセッション名には 【短い作業名】MMDD・作業番号・具体的内容 を使用します。自動改名やID連携はサービス別の実機検証後に有効化します。
